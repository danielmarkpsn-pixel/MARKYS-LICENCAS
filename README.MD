            Módulos do MARKYS LICENÇAS
- Início: indicadores de licenças e faturamento.
- Sistemas: cadastro dos softwares comercializados.
- Clientes: gerenciamento dos compradores.
- Licenças: ativação, bloqueio, vencimento e renovação.
- Dispositivos: controle de aparelhos autorizados.
- Financeiro: mensalidades, pagamentos e inadimplência.
- Auditoria: histórico de operações administrativas.
- Configurações: planos, valores e permissões
